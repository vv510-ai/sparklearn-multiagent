# LearnLoop 讲解视频视觉规范

这份规范保证每条讲解视频都有统一、克制、高级的品牌气质。分镜里的 `visual_style` 可以在此基础上微调，但不能偏离。

## 画布与版式

- 画布 1920×1080，四周安全边距 96px；底部 170px 留给字幕，主体内容不要进入这个区域。
- 每一镜三层结构：左上角小标签（章节序号 + 镜头标题，24–28px）、中间主视觉区、旁边或下方的少量说明文字。
- 一屏最多一个视觉焦点、三条文字要点；宁可多分一镜，也不要把画面塞满。
- 全片底部一条 4px 细进度线（品牌绿），镜头切换处有小圆点。

## 色彩

- 浅色为主：底色 #f6faf7，主文字 #052a20，次要文字 #3d5a50。
- 品牌色：品牌绿 #0e7a5a（主要强调）、青绿 #12a38a（图形与连线）、薄荷 #7ee2b8（高亮底条与发光），金色 #f2c46d 只用于“关键结论”这样的少量点缀。
- 章节卡或强调镜头可用深色：底色 #052a20，文字 #eafaf3，高光用薄荷色。
- 不用纯黑、纯红；对比关系用明度和品牌绿的深浅来表达。

## 字体与字号

- 中文用 PingFang SC，数字和英文可用 Helvetica Neue；都用 `@font-face { src: local(...) }` 声明。
- 标题 72–96px、字重 700、字距略收紧；小标题 44–56px、字重 600；正文 36–40px；字幕 40–44px；行高约 1.35。
- 公式、数字用大字号单独成行，关键数字可以做计数动画。

## 质感

- 玻璃卡片：`background: rgba(255,255,255,0.62)`，`backdrop-filter: blur(24px)`，1px 白色半透明描边，圆角 28px，柔和阴影 `0 24px 60px rgba(5,42,32,0.12)`。
- 背景可以有缓慢移动的柔和光斑（品牌绿、薄荷色，低不透明度），制造空间感，但不能抢主体。
- 图形用细线条与圆角几何体；箭头和连线用 SVG 路径描边动画画出来。

## 动效

- 入场 0.6–0.9 秒，缓动用 power3.out 或 expo.out；位移 24–48px，配合透明度；同组元素依次出现，间隔 0.08–0.12 秒。
- 强调：轻微放大到 1.04 并加薄荷色高光底条；变化前后的状态要停留足够时间让人看清。
- 转场 0.4–0.8 秒：推拉、遮罩擦除（clip-path）、模糊溶解三选一，全片风格统一。
- 避免弹跳过度、旋转乱飞、频闪和与内容无关的粒子特效。

## 片头与片尾

- 片头前 0.8 秒左上角淡入品牌小标识“LearnLoop 知行循证”，随后进入开场问题。
- 片尾卡：回忆链（3–5 个关键词用箭头串起）+ 自测问题 + 品牌标识，停留不少于 4 秒。
