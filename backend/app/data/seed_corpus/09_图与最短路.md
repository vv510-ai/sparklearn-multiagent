# 图、遍历与最短路径

## 图的存储
图是一种描述“对象以及对象之间关系”的非线性数据结构，通常写成 G=(V,E)：V 是顶点集合，E 是连接顶点的边集合。图分有向/无向、带权/无权。邻接矩阵 O(V^2) 空间,判断任意两点相邻 O(1),适合稠密图;邻接表 O(V+E) 空间,枚举邻居高效,适合稀疏图,是绝大多数算法的默认选择。

## 深度优先搜索 DFS
DFS 沿一条路走到底再回溯,递归或显式栈实现,O(V+E)。应用:连通分量、拓扑排序(逆后序)、检测环、求割点桥。注意必须用 visited 标记防止重复访问与死循环。

## 广度优先搜索 BFS
BFS 用队列按层扩展,O(V+E)。无权图中 BFS 首次到达某点的层数就是最短路径长度,这是它最重要的性质;也用于二分图判定、状态空间搜索(走迷宫、单词接龙)。

```python
from collections import deque

def bfs_shortest(graph, s, t):
    dist = {s: 0}
    q = deque([s])
    while q:
        u = q.popleft()
        if u == t:
            return dist[u]
        for v in graph[u]:
            if v not in dist:        # visited 检查在入队时做
                dist[v] = dist[u] + 1
                q.append(v)
    return -1
```

## 拓扑排序
仅对有向无环图 DAG 存在。Kahn 算法:不断取出入度为 0 的点并削减其邻居入度,配合队列 O(V+E);若输出点数 < V 则图有环。课程先修关系、编译依赖即拓扑序应用。

## Dijkstra 最短路径
单源最短路,要求边权非负。贪心:每次从未确定集合取距离最小的点松弛其出边,优先队列实现 O((V+E) log V)。负权边会破坏"已取出即最短"的前提,需改用 Bellman-Ford O(VE),它还能检测负环。多源最短路用 Floyd 三重循环 O(V^3)。

## 易错点
1. Dijkstra 用于负权图得出错误答案——这是最经典的误用。
2. BFS 在出队时才标记 visited 导致节点重复入队,复杂度恶化。
3. 拓扑排序忘记判环,对有环图输出残缺序列。
4. 邻接矩阵跑稀疏大图,内存与遍历双双爆炸。
