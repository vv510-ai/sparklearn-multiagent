# 学习请求与资料使用改进

状态：依据 2026-09-23 至 24 日对话实施；本地回归通过，生产实测待发布后记录。

## 已确认目标

用户希望保留 DeepSeek、Kimi 的回答能力，以自己的资料学明白，并支持个性化备考；要求边改边解释。当前切片修复请求传递、资料使用和结果状态，不承诺考试提分或完整真题覆盖。

## 行为与验收

| 编号 | 目标行为 | 验收 |
| --- | --- | --- |
| FR-01 | 聊天复合请求完整传给检索和生成；明确要一图看懂时使用对应模板 | 截图原句保留考点、占分、方法、网站能力和图的要求，生成 one_page 而非普通笔记 |
| FR-02 | 普通学习对话默认资料优先，允许明确标识的通用补充；用户要求仅依据资料时严格执行 | 无检索命中时普通问题仍可交给真实模型；严格模式不编造资料内容；本轮范围要求优先，后续追问继承 |
| FR-03 | 资料引用与通用补充分别说明，不能把未核验内容标为已被资料证明 | 无资料不得虚构引用；有补充的图不标为全部经过资料核验；资料内整理、对话归档和诊断补救保留原有严格边界 |
| FR-04 | 课程总览能使用本课程各章节及已有考试结构，产品能力问题使用真实功能说明 | 六级整课问题不会因标题不匹配章节而清空命中；材料独占范围不会偷偷混入其他课程 |
| FR-05 | 没有可用资源就报告未完成，部分完成要说明 | unavailable 文档不再提示“学习内容已经准备好了”；图片失败保留文字与重试语义 |
| FR-06 | 同一用户可通过简洁的资料范围控制明确选择，仅影响当前学习空间 | 控件、请求参数和生成结果一致；不越过账户与书本资料所有权检查 |

## 实现约束与取舍

- 继续使用统一模型网关，不新增模型供应商或模型服务。
- 资料优先的补充规则用于教学对话和讲解产物；复测、判分、诊断补救、原文归档保持严格证据约束。
- 本阶段不扩充为完整六级真题库，也不将自动联网检索描述为已实现能力。公开考试结构使用可核验、有日期的已有记录。
- 不以关键词命中或本地引用检查声称事实已经全面核实；通用补充明确标识。
- 模型质量与个性化效果仍需真实样本对照，不能以离线替身测试代替。

## 已知限制

- 中文资料范围识别使用有针对性的规则及 UI 显式选择，并不等于完整语义理解；新增漏判需持续加入反例。
- 允许补充的答疑在完整引用编号检查后展示正文，首段等待时间可能增加；不会将引用编号有效描述为语义已核验。
- 选择在当前页面按课程保存，刷新后恢复自动模式；自动模式仍依据该课程当前会话的用户明确要求。
- 讲解产物和答疑开放补充；其他产物继续沿用其资料约束，严格模式对空来源统一阻断。
- 课程知识与题库覆盖、长资料跨章节检索、真实学习成效评估仍需后续专项工作。

## 教学要点

1. RAG 是查资料的步骤，不能承担完整的用户意图理解。
2. source_ids 表示去哪里找，source_policy 表示找到或找不到之后允许怎样回答；二者不能混为一个布尔条件。
3. 原始问题必须穿过 API、路由、规划、检索、生成，不能只保留课程名。
4. 资源存在、生成成功、引用有效、事实正确、用户学会是不同的判断。
