# 大学英语六级课程接入

## 用户路径

新用户在注册引导的“这次，我们一起学什么”选择 **大学英语六级（CET-6）**；已有用户在左侧 **新建课程** 选择同名卡片。每门课沿用 notebook 隔离的资料、画像、作答、对话与计划。用户仍可上传自己的课本；绑定上传材料准备课程时，采用已有的按实际取样范围生成课程流程，不把内置讲义冒充用户教材。

六级引导支持多选词汇、听力、阅读定位和表达困难，保留实际可用时间与目标日期。回答传入计划和讲解上下文，自述不增加能力分。

## 首版边界与教学内容

- 6 个模块：词汇与语境、仔细阅读与推断、段落匹配与长篇阅读、听力信息提取、写作结构辨析、翻译句法辨析。
- 18 道原创起点题（含多选辨析）与 54 道不同的单选新题；每模块 3 + 9。短段匹配并非正式长篇题，基础句子辨析并非整篇输出测评。
- 12 段原创合成英语音频：起点 3 段，新题 9 段。先听完整音频再提交，文字稿延迟到解析展示；音频故障可以跳过，不据此记错。独立作答是学习者在无外部提示情况下的自报学习证据，不是防作弊考试。
- 写作、翻译提供实际输出题及草稿框；草稿按测评 id、模块保存在当前浏览器，提交后进入同一课程的持久化对话，由小知反馈并要求自己修订。选择题不能自动勾完这两类输出任务，模型反馈不更新独立掌握度或给官方分数。
- 新题沿用现有并发保护、重复提交幂等、跨测评去重和隔日／再隔三天的换题复测。报告保留原始起点，计划根据后续独立证据更新。该流程未做学习增益试验，不能声称能提高特定分数。

## 来源与 RAG

官方考试结构直接核对：[教育部教育考试院六级笔试介绍](https://cet.neea.edu.cn/html1/report/16123/201-1.htm)，核对日期 2026-09-18。此页面提供考试结构事实；未复制历年真题、第三方备考教材或付费课程。

正文来自本站原创 [六级起点学习指南](courses/cet6-guide-v1.md)，以 CC BY-SA 4.0 发布。按章节记录正文、URL、版本和 SHA-256；prepared course 与 assessment 都保存快照，检索只取本课固定版本的正文。已将原先仅 Python 可用的教材检索扩展为按当前课程的教材元数据读取，仍保持账号和课程隔离。自然语言匹配使用当前图谱中的常用表达，包含多个主题的提问不强制缩成一个主题。

不引入新向量库、付费语音依赖或第三方教材抓取服务。复用已有测评、画像、计划、教材溯源和统一模型入口；合成音频作为静态文件随版本部署。

## 维护

内容：`backend/app/data/cet6_course.py`。更新版本时一并更新指南、题库、脚本与音频。

在 backend 目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/export_cet6_course.py
powershell -NoProfile -File scripts/build_cet6_audio.ps1
```

第二条需要 Windows System.Speech 的 Microsoft Zira Desktop 英语语音。只用于维护时离线生成；Linux 部署直接服务已提交的 WAV。每段音频及对应脚本的哈希记录在 `backend/app/data/cet6_audio_manifest.json`。音频为 16 kHz、16 bit、单声道，共约 5.7 MB。

验证：`backend/tests/test_cet6_course.py` 检查课程隔离、实际可听波形与脚本哈希、起点／新题区分、跳过不计错、计划与引用传递，以及选择题不完成实际写作。`frontend/e2e/cet6-course.spec.ts` 在隔离 Chromium 中检查真实入口、自然媒体结束事件、草稿恢复、提交、手机布局；`PLAYWRIGHT_REAL_MODE=1` 额外验证线上模型讲解与资料引用。自动播放测试用静音四倍速解码，不代表听力教学质量评估。
