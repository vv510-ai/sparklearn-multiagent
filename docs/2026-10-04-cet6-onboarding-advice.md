# 首次进入六级课程的备考建议

## 已确认的体验

学生在开始练习前填写困难、目标、每天可用时间、考试日期和可选历史成绩，保存后直接获得《你的六级备考建议》。报告包含情况理解、练习重点及理由、阅读/听力/写作/翻译/词汇的方法、近期安排与真实练习入口。无需先完成测评。信息不足时给出起步建议，不虚构弱项；后续练习用于修正判断。

## 实现决定

- 复用现有 FastAPI、Next.js、Pydantic、账号/课程隔离和统一 `llm_complete` 网关，不新增外部依赖。相对于在偏好 JSON 中混存长报告，独立保存报告可避免词卡目标更新覆盖分析。
- 保存偏好与生成建议分离：保存成功后进入报告页，后台生成并轮询恢复；账号与课程内按输入快照去重，过期任务允许显式重试，迟到结果不得覆盖新任务。
- 日期、时间预算、七天任务、阶段说明和引用链接由程序控制；模型可以使用已填写的成绩和官方考试数字解释判断，不能另写一套日程。既有模型路由继续生效，启用思考模式，实际模型记录在报告中。
- 官方分数解释与考试结构作为固定、带核验日期的参考资料；模型不编造引用网址或将训练正确率转换为报道分。官方常模参照仅用于初步安排，不代表当前全国排名。
- 所有成绩可留空，目标分不默认设为 425/450；考试日期为空时只安排第一周，过去日期提示调整。每天少量时间按天轮换；每一天的任务分钟数不超过填写值。
- 报告会标明基于自述和历史成绩。演示环境或真实模型失败时提供明确标注的基础安排，保留输入并允许重试。
- 第二版根据真实生成内容复核，补足六级听力题型、汉译英方向、未做过材料的能力检查和自述归属约束；方法段落不再附加每日训练要求，短时学生按天轮换主项。校验只负责已知结构与一致性问题，不能代替逐段阅读。

## 第三版：先解释成绩，再给初步建议

用户反馈第二版像通用操作清单，缺少对成绩的具体解读。第三版调整提示词、输出合同、事实校验和长文展示，保留现有模型路由；不把换模型当成已证明的解决办法。

- 新增 `score_analysis`、`plan_explanation`、`closing`；五项方法使用完整 `body`，可用段落、条件分支、例句和错因举例展开，不再限定每项固定步骤数。
- `target_breakdown` 仅在用户填写目标和全部分项、且目标尚未达到时使用；三项范围与合计必须正确，页面明确标为讨论用目标组合，不作成绩预测。未填目标时不自行补成 425 或 450。
- 提示词提供三种不同结构的示例：353/145/112/96、420/100/210/110，以及只填总分。重点应随分项和自述改变，不把低分直接诊断为词汇量不足。
- 允许经过检查的成绩、分差、考试比例与用时。校验已知成绩、目标、每日预算、分项上限、来源及明显的保证性表述；语义质量仍需逐段阅读真实模型返回。
- 正文支持受限 Markdown 与引用标记，引用只能解析到固定来源。增加目标对照表、段落间距和手机表格滚动；旧报告仍可读，并提示主动生成升级版。
- 模型只获得每日时段预算，页面按实际建议重点生成轮换表，避免正文照抄另一重点的日程。程序补齐固定引用的简写与遗漏的新材料检查提醒；允许正常说明已填时间、考试用时和明确假设，仍拒绝额外周期任务或把报道分再次加权。
- 质量验收关注：开头是否有具体判断、是否解释取舍、是否有可理解的例子、是否尊重时间预算、信息不足时是否给出可行动的起点。通过 JSON 校验和达到字数不等于内容合格。

## 验收范围

1. 完整分项、只有总分、无成绩、20/90 分钟、未知/临近/过去考试日期。
2. 首次进入、跳过、保存后自动生成、失败重试、刷新/新对话恢复、修改后的旧报告提示。
3. 账号/课程隔离、重复请求、过期任务、迟到结果、未知链接和结构错误。
4. 桌面与手机可读、键盘可操作，报告中的练习入口真实可达。
5. 后端完整回归、前端构建、浏览器流程及线上同版本真实模型生成；代码和 Mock 不能代替线上内容验收。
