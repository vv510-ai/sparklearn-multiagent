## Windows 适配

本机已复用并核验 Windows Python 3.12 与 Node.js 24 环境；前端在 Windows 使用 `next start`，避免 Mac/Linux standalone 软链接要求。启动器处理 `Scripts/python.exe`、`.cmd`、中文编码、进程身份、重复点击互斥和端口占用。后台进程隐藏运行，停止时只处理本启动器记录且身份吻合的进程。

视频工具适配 Windows Chrome、ffmpeg/ffprobe 可执行文件与进程停止；edge-tts 不可用时可尝试 Windows 中文系统语音。系统未安装对应中文声音时仍可能报错，不能以工具安装成功代替真实成片验收。

本机配置在 `backend/.env`、`.native/`，数据库沿用 `backend/sparklearn.db`。原 Windows 学习数据和认证密钥已保留。不要把本机 `.env` 覆盖到云服务器，也不要提交这些私有文件。

若在另一台 Windows 电脑重新安装，先安装 Python 3.12、Node.js 22.19 或更高版本和 Git，随后在源码目录运行 `py -3.12 scripts\mac\native.py setup`；本次没有验证全新 Windows 机器从零安装。

## 2026-10-17 歌曲与小云雀接入

按本次选择，讲解视频使用小云雀；本机启动配置也默认选择小云雀，不再自动开启 Claude 视频。学习工坊的入口说明同步修改。当前小云雀链路制作约 10 秒的关键概念片段，完整讲解配有独立讲稿、分镜与语音；不将短片描述为已经合成的长篇讲解视频。

记忆歌曲沿用苹果包已有的 Suno 配置，经用户确认使用第三方 `https://www.suno-api.io`。正式服务的私有配置保存在阿里云 `/opt/sparklearn/shared/.env`，由后端和生成任务进程共同读取；只写入歌曲配置和视频选择，不覆盖原有文字模型、账号与学习数据。生成时先整理知识点、编口诀、选择曲风、写歌词并核对，再提交演唱，最后将音频与封面存到本站。

本次补齐收费任务的恢复处理：歌曲受理编号立即写入持久任务记录，查询或下载暂时中断时继续处理原订单；提交后连接中断时暂停核对，避免换域重复提交。视频提交依靠实际 HTTP 超时，避免另一个更早的计时器丢弃已经受理的编号；正常受理后继续查询同一任务，将 MP4 保存到本站，并写回资源记录。

使用入口：进入课程，在“看懂”中选择“讲解视频”，在“记住”中选择“记忆歌曲”。生成结果包含视频/歌曲播放器；歌曲支持切换两个版本、歌词跟唱、填空检验和下载。当前生成结果与课程、账号关联，刷新后从原课程的学习资源继续查看。
