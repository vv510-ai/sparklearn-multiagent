# 笔记规则与渐进学习引导

## 本轮结论与范围

上一轮升级明确参考了飞书的“解释”Prompt，以及 teaching-animation、english-vocabulary-notes、one-glance-knowledge-map。不能把它描述为已经运行 course-notes-orchestrator 的完整流程。本轮读取该 Skill，并用它的 `check-prompts` 只读拉取关联飞书文档；六个独立块成功，现有标记检查 `problem_count=0`，文档修订为 **1629**。标记检查通过不等于逐条语义审计通过。

当前应用采用其中适合交互学习的笔记原则，版本为 `2026.09.22.2`：正文完成后提炼全局回忆总览、保留独有细节与原文教学 Prompt、解释推导与条件、题目反向提取考点、章末记忆锚点、避免重复及牵强类比。新增规则独立维护在 `backend/app/prompts/shared/course-notes.md`，用于完整主题笔记与对话笔记。聊天教学规则在 `shared/learning-coach.md`。

**这不是完整笔记流水线的移植。** 网站仍基于本次检索到的至多 5 个相关片段与可用对话整理，没有运行整份附件逐页视觉检查、独立第二轮全文重读、图片保真/哈希验收和飞书自动发布。资源卡直接说明这一范围；超出对话字符预算的较早内容也会在模型输入中标明。原 Skill 的全材料处理与严格门禁仍适合另行开展的完整课程笔记任务。

## 用户怎样逐步发现工具

1. 保留已有的五步引导：目标 → 课程与基础 → 当前困难与帮助方式 → 可用时间及开始时机 → 核对范围后短测。既有选择继续传入计划和教学，无需重复回答。
2. 目标页新增可选的按钮用途导览；帮助偏好明确为可修改的当下选择，不能成为性格或能力标签。时间页把用户填写的开始时机回显为一个可以执行的小步骤。
3. 学习工坊初始只展示两种教学工具，以及测评、网课、归档和设置入口。三轮有效问答后展示四个整理/练习工具。全部能力随时可以展开，导览无需强制走完。
4. 一条成功结束、确有教学焦点、正文至少 80 字符、未生成资源的问答才计数。失败、停止、产品操作、纯资源生成不会推进阶段。计数不能推断掌握程度。
5. 第三轮开始按当前提问的关系、复习或练习意图，提示一个工具：一图看懂、框架导图、本次学习笔记或巩固测验。提示不调用模型或生成接口，选择后才生成。
6. 接受、点“稍后”或继续输入问题，都会留下至少三轮的间隔；同一工具不反复推荐。可关闭本次对话提醒。状态按账户、书本、会话保存在当前浏览器的 sessionStorage，只存计数与选项，不存聊天正文；刷新可恢复，新会话和另一本书互不影响。浏览器储存不可用时仍能在当前页面使用。

“三轮、80 字符”是可调整的产品启发式，**不是经实验验证的最佳学习阈值**。实时大模型继续负责讲解与已有的“生成下一步问题”；工具提醒采用明确规则，两者不混称为模型实时判断。

本次还修正了两个会影响整理真实性的问题：对话笔记接口现在保留多个主题的可用历史，普通主题笔记仍限定当前主题；学习笔记不再过滤材料里的教学 Prompt、命令和代码围栏。普通非代码讲解和一图看懂继续采用相应的呈现规则。

首次真实模型验收还发现：同一资料段落对比多个概念时，主题过滤只接受第一个识别到的概念，会把讲“栈与队列”的段落从“队列”的笔记中排除。本轮改为接受段落实际包含的目标概念，同时继续排除无关章节；回归同时验证比较段落和老师模板保留、无关排序章节排除。

自定义课程还会保留自然语言问题作主题名，不能直接把“栈和队列有什么区别？请用资料中的两个例子说明先后顺序”整句当成必须匹配的资料关键词。现从问句抽取“栈”“队列”等主题，排除后面的教学要求，兼容这些单字概念；以真实生成失败案例补充了回归。

## 参考依据与取舍

这是对公开流程的参考，没有复制开源代码、安装其依赖或新建多智能体服务。

| 来源（2026-09-22 核验） | 采用的思路 | 边界 |
|---|---|---|
| [DeepTutor](https://github.com/HKUDS/DeepTutor)，`48e3627adad8939cfc2105bf0960194ecd1b1118`，Apache-2.0 | 以聊天为主要入口，常用动作就近呈现，更多能力收纳；课程上下文持续有效 | README 流程参考，不把上游所有能力当成 LearnLoop 已实现 |
| [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)，`05d782090f5252eb58f83be2d5140c5a5b946a6e`，MIT | 根据材料与学习目标组织课堂，允许持续提问和调整 | 本轮没有移植完整课堂生成器 |
| [Ryan 与 Deci，2020，自我决定理论综述](https://selfdeterminationtheory.org/wp-content/uploads/2020/06/2020_RyanDeci_IntrinsicandExtrinsic.pdf) | 支持自主选择，解释建议的理由，提供明确且可完成的结构 | 设计依据，不是本产品已经获得心理或学习效果验证 |
| [IES 学习与教学实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) | 示例后独立尝试、主动回忆、间隔复习与深层解释问题 | 各建议证据强度不同，不能推出“聊天三轮后画图一定有效” |
