# 课程内学习改版

## 用户问题与落实

原来六级仅有六个概览点，左侧教材和课程范围占用较大空间，真实资料与课程库又分别进入独立页面。此次把学习放回当前 notebook：创建课程 → 进入当前章节 → 打开对应原材料 → 独立完成任务 → 核对订正 → 保存并继续。左侧只保留课程、上传资料、折叠章节；右侧全部已有能力工具继续保留。

## 内容与证据边界

| 课程 | 单元 | 主来源 |
| --- | --- | --- |
| 大学英语六级 | 28 | 教育考试院题型说明、新东方整理真题与专项模拟 |
| Python | 10 | Harvard CS50P 原题集，Python 官方教程许可摘录 |
| 数据结构与算法 | 14 | Hello Algo 各章、MIT 原课程作业 |
| 高数入门 | 14 | MIT 微积分分节、例题与练习 |
| 日常英语 | 6 | British Council 听读材料、Test-English 词汇练习 |

来源元数据复用 `study_materials_v1.json` 的 59 个入口。六级“本课更多教材与真题”包含 33 套题面入口、11 个考期，可切换专项模拟及图书配套。

本站编排学习顺序和学习任务，没有把任务说明冒充机构原题。外站资料未自动抓取为站内全文；只有已取得许可的 Python 官方摘录可站内阅读和引用。模型不会把这些外链当成读过的全文，需要用户提供具体原题、截图或上传材料。新东方题面和答案属于机构整理，并非教育考试院原始发布；音频必须与卷次配套，已知标题或配套疑点在章节任务和来源说明中保留。外站目录可公开访问不等于完整课程或所有配套材料免费开放。

旧平台原创讲义、练习及英语示例场景不再作为五门默认课程的新学习路径。旧数据和已形成报告保留；右侧英语自定义场景、巩固测验等按用户主动请求继续提供，生成内容不标为教材原题。教材目录扩展与旧能力图谱分开保存，72 节学习清单不冒充 72 个已验证掌握点。

## 进度与恢复

`GET /api/notebooks/{id}/study` 返回版本化单元及当前账户进度。`POST /api/notebooks/{id}/study/{unit_id}` 使用 revision 条件更新；重复相同提交幂等，其他页面更新时返回 409 并保留草稿。草稿按账户、课程、单元及路径版本隔离。完成要求自查阅读、练习、订正及最少一条结果；不修改 BKT 或测评掌握度。普通编辑与保存保留完成标记，取消必要勾选才撤销完成。复习日期按中国时区显示。

## 验证

后端回归覆盖真实默认课程无原创题库、鉴权、跨账户与跨课程隔离、版本冲突、重复提交、历史报告读取不重建指南。旧通用评分、复测、隔离测试改用明确的自定义测试课程，内容只在测试里装载，生产来源策略没有豁免。

浏览器验收覆盖五门课从注册和创建进入章节、原材料链接、全部右侧生成工具、空历史只读、六级更多资料、Python 官方摘录、完成下一节、刷新恢复、冲突草稿、保存失败时切换章节，以及桌面与手机布局。实测证据保存在 acceptance 报告与 Playwright 截图中。外站内容可用性不由该浏览器测试保证；真实模型输出质量不在此次无模型流程验收内。
