# SparkLearn 星火学伴 · 使用教程

本教程按一名学生的真实学习旅程组织:从一句话建档,到拿到专属资源、按路径推进、随时答疑、用评估驱动下一步。全程界面截图位以【截图:…】标注,录制演示视频时按本顺序即可。

## 0 进入系统

浏览器打开 http://localhost:3000。顶部导航四个入口:学习对话(CHAT)、资源工坊(FORGE)、学习路径(PATH)、学情评估(EVAL)。右上角"MULTI-AGENT · 数据结构与算法"指示当前课程。【截图:首页空态】

## 1 第一次对话:让系统认识你(学生画像)

在首页输入框用自然语言描述自己,例如:"我是大二学生,两周后期末考,想先攻克二叉树和动态规划;我喜欢看图理解,总是错在递归边界。"按 Enter 发送。

观察两件事:左侧助手开始流式回应;右侧 **AGENT TRACE** 面板自上而下点亮——PRF 画像智能体先呼吸闪烁,电文行显示它正在抽取的维度,随后 ORC 编排器接管路由。切到右侧 **PROFILE** 页签,可以看到雷达图与八个字段已经更新:目标变为"期末备考",认知风格变为"视觉型",易错点出现"递归边界",版本号 +1。画像是"随学随新"的,之后每轮对话与每次答题都会继续刷新它。【截图:对话中 AgentTrace 点亮 / 画像页签更新】

## 2 一键铸造专属资源(资源生成)

进入"资源工坊"。在知识点行选「二叉树」,资源类型保持默认勾选(图文教程 / 思维导图 / 智能题组 / 讲解视频),可在目标框补一句"偏好可视化讲解",点击橙色按钮"开始生成"。

右侧遥测面板会完整重演一次编排:画像 → 编排器 → 资源规划(给出生成什么、为什么)→ 路径规划 → **DOC / MAP / QUZ / MED 四个节点同时呼吸**——这是四类资源真正的并行生成 → 评估质检收尾。生成完成后顶部出现一句绿字总结(几份资源、是否全部通过双层校验)。【截图:四节点并行呼吸】

本次产出区逐张展开查看:

图文教程卡片:章节化讲解,内嵌 Mermaid 图解,正文事实性句子带 [^n] 脚注;卡片底部 **CITATIONS** 区列出每条脚注对应的《数据结构与算法》章节来源——这就是"引用溯源"。若个别表述未在教材中找到依据,卡片右上会出现"溯源复核"橙标并在文末提示,系统不隐藏不确定的内容。【截图:引用脚注与 CITATIONS】

思维导图卡片:可缩放、可折叠分支的交互脑图,覆盖概念、性质、操作、复杂度与易错点。【截图:markmap 脑图】

智能题组卡片:5 道按你当前掌握度定档的题(单选/填空/判断/复杂度/简答)。先不要做,留到第 4 步演示评估闭环。

讲解视频卡片:配置了火山 Seedance 密钥时显示生成任务与最终视频;未配置时显示完整分镜脚本、可一键复制的 Manim 动画代码(本地 `manim -pql scene.py 类名` 即可渲染)与旁白文本——降级模式同样可演示。【截图:视频卡片/降级卡片】

页面下方"我的资源库"保存历史产出,刷新后仍在(数据库持久化)。

## 3 看清"先学什么、为什么"(学习路径)

进入"学习路径"。整张课程知识图谱分层铺开:薄荷绿节点已掌握,电光蓝节点可学习,灰色节点先修未达标;**橙色虚线呼吸框**标注系统当前最推荐的下一步;每个节点下方的小进度条就是你的掌握度。

点击任意节点,右侧给出"学习处方":掌握度、状态与一句自然语言推荐理由(例如"命中学习目标,且循序渐进优先低难")。右下"推荐序列"列出按优先级排好的前五个就绪知识点。点击"按最新画像重排"可手动触发重算;更常见的情况是——做完题它会自己变,见下一步。【截图:DAG 全景与节点处方】

## 4 做题,看系统如何为你而变(学习评估闭环)

回到资源工坊,展开刚才的题组卡片,逐题作答(故意答错一两道效果更直观),点击"提交并更新我的掌握度"。

提交瞬间发生四件事:每道题即时判分,错题展示参考答案、详解与**错因标签**(并提示已回写画像);报告区给出本次正确率与该知识点的**新掌握度**;画像的 error_prone 维度收录了你的错因;学习路径按新掌握度自动重排。对答错或已经揭晓的题,报告下方还会出现“无提示恢复测”:重新独立完成全部待恢复题后,系统才把答对结果记为新的掌握证据,并再次校准掌握度与路径。之后进入“我的学习情况”,“今日复习”会按 1、3、7、14、30 天安排这些题的独立回忆;连续答对逐步拉长间隔,答错则回到 1 天。“学习证据账本”会逐轮展示首次作答、复测与间隔复习的判对数、计入掌握数、支持使用量，以及掌握度从多少变到多少；这能解释为什么“看过答案后答对”不会被误算成已经掌握。现在切到"学习路径"页验证:刚才知识点的进度条变了,推荐序列可能也变了——这就是"评估驱动学习"的闭环。【截图:判分详解、无提示恢复测、学习证据账本、今日复习与重排后的路径】

进入"学情评估"页查看全貌:左侧画像雷达与两个统计卡(累计答题轮次、平均正确率),右侧 16 个知识点掌握全景条形图(绿/蓝/橙三档)、优先补强与优势区提示、近期学习事件流水。【截图:评估总览】

## 5 随时提问,带图也行(智能答疑)

回到首页,直接提问,例如:"为什么 Dijkstra 算法不能处理负权边?"回答**逐字流式**出现,风格是先点拨思路再给完整解答;结束后自动附一张 Mermaid 流程图解(对视觉型画像的你尤其友好)与教材引用列表。遥测面板此时只点亮 TUT 答疑导师——编排器识别这是答疑意图,没有走生成流水线。

联网环境下还可拍照搜题:点击输入区上传题目照片(或在调用方传 image_base64),讯飞 OCR 会先还原题面(进度提示中可见识别结果),再针对该题作答。【截图:流式答疑与图解】

## 6 三分钟评委演示脚本(建议)

第一分钟,首页一句话自我介绍 → 指出右侧画像实时变化与 AgentTrace 点亮,讲"随学随新八维画像 + 编排可视化"。第二分钟,资源工坊生成二叉树四件套 → 指出四节点并行呼吸与卡片上的引用脚注/溯源标记,讲"并行 fan-out + 引用溯源防幻觉"。第三分钟,做题提交 → 跳转路径页看图谱变化,讲"BKT 评估闭环驱动路径自适应";收尾用一句"全程未配置密钥也可离线复现"(若现场即为演示模式,直接展示 /api/health 的 demo_mode 字段)。
