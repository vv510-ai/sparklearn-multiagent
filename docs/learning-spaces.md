# 注册引导、课程摸底与后续学习

## 已实现的流程

注册完成即展示「你希望学伴先帮你完成什么？」多选问题。学习者可以同时选择看懂资料、系统入门、备考、独立解题、计划复习和项目实践，并明确当前优先项。

1. 目标与帮助价值：说明接下来会用题目找起点，并准备今天能开始的任务。
2. 课程与材料：选择数据结构、Python、高数入门，或输入其他主题；可直接上传并选择最多 6 份已解析材料。
3. 学习需要：困难和支持方式支持多选；先前经验只影响起步方式，不作为成绩。
4. 时间安排：学习日、每天可用分钟、目标日期及方便开始的时机。
5. 核对范围：展示具体知识点及实际资料取样位置，允许取消知识点，再开始独立作答。
6. 起点测评：单选、多选、选填信心、还不会、跳过；每题提交后保存，刷新及再次登录直接续答。
7. 报告与计划：按表现、目标、先修关系和时间容量安排学习与复习，并附讲义、例题、错因解释和真实材料摘录。
8. 后续学习：答疑、资源生成和练习继续读取当前课程的目标、困难、帮助偏好、时间、测评证据及绑定资料。

自述草稿保存在当前浏览器；核对后的课程及正式测评、计划、画像存储在服务器。用户可暂时跳过引导，通过工作台的起点测评入口继续。引导状态接口失败显示重试，不能把服务故障解释为已完成引导。

## 能力范围

| 课程 | 当前内容 | 解释边界 |
| --- | --- | --- |
| 数据结构与算法 | 原有 16 知识点图谱、题库和讲义；短测、基础及全面模式 | 自编课程题，不是标准化考试 |
| Python 入门 | 变量、分支、循环、函数；12 道自编题及讲义 | 只覆盖 4 个入门知识点 |
| 高等数学入门 | 极限、导数、积分及应用；12 道自编题及讲义 | 只覆盖 4 个入门知识点 |
| 其他主题及上传资料 | 模型生成 3–6 个代表性知识点，每点 3 题，至少 1 道多选；配套讲义 | 初步起点检查，答案与难度未经教研标定；不能据此声称测得整门课的能力 |

上传资料每份最多均匀取样 6 个解析片段，每个片段最多 1600 字符。页面公开取样数量和位置，源版本以完整解析正文的 SHA-256 记录。文本资料显示片段位置；PDF 显示解析页码。按选中的内容出题，覆盖不到的内容不标成已测。

出题校验检查结构、题型、合法答案、重复题干、解释以及引文与原文的逐字对应；这不等于已经证明答案语义正确。校验失败不保存伪题库，原资料和浏览器选择保留供重试。不提供通用性格诊断，也不把偏好的媒体形式当作固定“学习类型”。

## 数据与执行

- `LearningSpace` 使用 notebook 主键及用户所有权，独立保存 `course`、`data` 和 `path`。PostgreSQL 启用租户行级策略。
- `learning_scope.course_scope` 通过 ContextVar 绑定课程；`scoped_endpoint` 保留 FastAPI 的已解析签名。SSE 后台任务再次建立课程上下文。
- 测评保存出题时的完整课程快照、题库版本与作答。公开接口不提前返回答案和私有讲义。
- 当前题库或范围变化后，旧测评不能重新写入新课程画像；旧资源版本不能再充当新范围的练习证据。原始记录保留。
- 计划、掌握度、复习、错题本、学习证据、路径和视频推荐按当前课程读取；旧无 notebook 数据仍保留在原数据结构空间。没有自动把历史全局掌握度复制给新科目。
- 非数据结构课程排除默认数据结构种子检索；无人工核验的视频条目时提供该课程的搜索入口，不把旧视频库移植成其他学科推荐。
- 提示词统一由 `prompt_templates.invoke_learning_prompt` 注入 `shared/learner-context.md`，继续经既有模型网关执行。用户资料与自述始终作为待分析数据。
- 练习后的计划调整只采纳新的独立题证据，保留初测报告，不将提示后答对或重复同题当作新的独立掌握证明。

## 心理学与开源参考

本轮直接复用本项目的 notebook、鉴权、资料解析、测评引擎、计划日历及模型网关，没有引入新的模型 SDK 或复制 OpenMAIC 代码。

[OpenMAIC](https://github.com/THU-MAIC/OpenMAIC) 调研版本为 `2cbd011c1f08d963c94e7b4478c44c750ea6ed6e`，仓库 LICENSE 为 MIT。吸收的是以下设计：

- `skills/agent-runtime/curriculum-planner/SKILL.md`：逐步澄清学习者、目标、时间、资料，并先核对大纲。
- `packages/@openmaic/generation/README.md`：内容生成与运行时、持久化解耦；本项目保留自己的模型网关及数据结构。
- `eval/zone-of-proximal-development/`：区分独立表现、帮助后的表现以及撤去帮助后的复测。本项目已有相关证据链，本次把它接入课程范围和目标上下文。该目录的合成本地验证不作为真实教学效果证据。

[Ryan 与 Deci 的自我决定理论综述](https://selfdeterminationtheory.org/wp-content/uploads/2020/06/2020_RyanDeci_IntrinsicandExtrinsic.pdf) 支持自主选择和有意义的能力反馈；[IES 学习组织实践指南](https://ies.ed.gov/ncee/wwc/practiceguide/1) 为提取练习、例题与间隔复习提供设计依据。它们支持流程选择，不证明本站已经产生特定学习增益。真实留存、学习进步和题目质量仍需要用户试点及题库标定。

## 验证与发布

离线后端全套 301 项通过；本地浏览器 10 项通过，覆盖注册、恢复、多选、DSA 短测/全面续测、Python 计划、多课程隔离、手机布局、资料阅读、重新登录及旧公开体验。`npm run build` 验证前端构建。

新增 `backend/tests/test_learning_spaces.py` 覆盖跨课程隔离、来源权限、异步上下文隔离、原文进入出题和配套材料、课程版本保护及所选知识点范围。该文件的模型输出使用桩，不能当作真实模型验收。

`frontend/e2e/material-course.spec.ts` 是独立的真实服务验收：使用新测试账户，实际上传自编生态学材料，经已配置模型出题，完成单选/多选、生成计划，再发起后续资料生成；检查持久化目标、时间、资料引用及课程归属。显式设置 `PLAYWRIGHT_REAL_MODE=1` 与 `PLAYWRIGHT_BASE_URL` 执行，默认离线回归跳过。截图和机器可读结果保存在 Playwright 的输出目录，不提交测试账户或运行产物。

发布遵循 `AGENTS.md` 和 `ALIYUN_DEPLOYMENT.md`：测试、构建、提交 main、推送、等待 ECS 自动部署，再核对部署提交、健康状态及真实核心流程。新增表是可兼容扩展，历史记录保留；部署失败由现有发布脚本回滚，不删除学习数据。
