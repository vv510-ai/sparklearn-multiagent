# SparkLearn Learning Quality Gate v1

这套质量门用于判断一次学习输出是否真的可靠，而不仅是接口是否返回成功。

## 必须保留的证据

每次学习运行应在 Trace 中记录：

- Prompt Skill 的 capability 与 version；
- 是否需要检索，以及命中的 source、chunk、score 和 citation；
- 所选 `source_ids` 与实际命中范围；
- fallback/degraded 的原因；
- grounding 结果和不受支持表述数量；
- 每个 Agent 的运行耗时。

Trace 不保存检索片段全文，只保存定位与评分信息，避免把资料内容重复写入事件流。

## 学习资源契约

| 资源 | 必要输入 | 资料边界 | 失败或降级行为 | 核心验收 |
|---|---|---|---|---|
| Tutor | 当前问题、画像、对话、`source_ids` | 有选择时只能使用所选资料 | 无命中时明确资料不足；轻量问候不检索 | 不泄漏全局知识；引用可定位 |
| Doc | 主题、目标、模板、对话、资料 | 事实来自检索资料，对话只描述学习过程 | 使用资料内确定性兜底 | 结构符合 capability；事实带引用 |
| Quiz | 知识点、难度、资料 | 题干和解析均在资料范围内 | 使用资料片段生成可核对题目 | 题数、答案、解析、引用完整 |
| Mindmap | 知识点、资料 | 选择资料时不扩展课程图谱关系 | 用命中片段生成最小节点 | 无相邻概念漂移 |
| Media | 知识点、目标、资料 | 分镜、旁白、动画均不得增加资料外事实 | 视频不可用时保留脚本或动画代码 | 降级原因可见且内容仍可学习 |

## 黄金案例

1. 选中资料包含答案：只引用所选资料。
2. 选中资料没有答案：明确说明资料不足，不调用模型补写。
3. 零基础引导：第一轮聚焦一个最小概念，不偷换成特殊类型。
4. 轻量问候：不触发 RAG。
5. 对话总结：形成一份可复用、资料可溯源的个人笔记。
6. 题目复盘：分析已有题目和选项，不另外生成新题。

优先使用确定性断言；只有无法通过结构和规则判断的语言质量，再增加 LLM-as-judge。
