# 六级阅读训练接入（第一阶段）

## 范围与题源

本次将独立阅读原型接入六级课程学习区，支持自备材料导入、首次作答、原文证据订正、短练习、站内复习任务及账号保存。听力、匹配、选词、写作、翻译和关闭网站后的推送属于后续阶段。

用户已选择「支持导入自己的真题；另附明确标注的体验示例」。两篇内置文章是原型原创的虚构教学情境，所有入口保留「非真题、难度未校准」标记。它们不会进入默认教材检索或测评题库。自备材料、标准答案、解释及出处由导入者提供，格式和证据片段可校验，不因此声称通过官方内容核验。所有导入材料仅属于当前账号和课程。

导入入口提供原文、题目、四个选项、答案、证据段落及解释的表单；高级区域支持 JSON 导入/导出。原文使用空行分段。每份材料 1–10 题，原文最多 60000 字符，JSON 文件最多 500 KB；每门课程最多保存 200 份阅读记录。标准答案必须指向有效选项，证据必须精确出现在对应段落。来源链接仅允许 HTTPS，不会由服务器抓取。

## 用户行为与验收契约

| 编号 | 行为 | 验收条件 |
| --- | --- | --- |
| FR-01 | 课程内阅读 | 六级课程显示今日任务；开始后进入专注布局；电脑并排、手机切换原文与题目，底部操作可见；可返回章节 |
| FR-02 | 账号保存 | 各步骤草稿自动保存；本机备份按账号、课程、记录和阶段区分；新浏览器凭同账号及深链接可恢复服务器记录 |
| FR-03 | 首次记录 | 服务器完成判分并冻结首次答案、帮助标记与自计用时；后续订正、短练习和复习不能覆盖 |
| FR-04 | 有依据订正 | 提交前不返回标准答案或解析；提交后显示原文证据及来源明确的解释；可带题目与作答到现有小知对话 |
| FR-05 | 间隔复习 | 当次短练习最多两题，后续复习覆盖全部错题和标记不确定的题；全部答对时仍安排巩固；提前或使用帮助不推进日程 |
| FR-06 | 冲突与失败 | revision 比较并更新；相同请求幂等；失败保留草稿；一页成功保存不能删除另一页较新的草稿；可核对后保存或恢复服务器版本 |
| FR-07 | 进展边界 | 今日任务与「我的学习情况」分别展示自备材料、示例、首次成绩和到期独立复习次数；不更新 BKT/测评掌握度或预测六级分数 |

复习按服务器时间安排，完成订正后的第一次为 24 小时后。复用现有 `1, 3, 7, 14, 30` 天间隔配置；到期全部答对后进入下一阶段，有错则回到 1 天。这里是产品初始规则，不是已经证明最佳的记忆曲线。使用帮助的事实在同次作答中累积；开始下一轮时重置。完成全部阶段称「本轮复习已完成」，不声称能力已掌握。

自备材料没有额外短题时，明确显示「原题重做」，不伪装成迁移测验。训练中查看过提示或答案由用户自述标记。即使未勾选，也只是自述独立；产品不能证明用户没有在其他地方看答案。

提醒是当前网站内的任务列表，不调用浏览器通知、不发送邮件，也没有创建任何 Codex 定时任务。章节自查日期、已有测验错题和阅读任务统一提供入口，保留各自记录含义。

## 实现位置

- `schemas/reading.py`：有界材料契约、来源和原文证据校验。
- `services/reading_training.py`：材料快照、阶段转换、独立首次记录、间隔复习、响应中的答案隐藏、revision 和请求收据。
- `ReadingTraining` / `reading_trainings`：按账号和课程隔离的持久记录，新表纳入 PostgreSQL RLS；仅新增表，不修改既有表结构或清理数据。
- `api/notebooks.py`：所有阅读接口使用服务端当前身份。兼容 BFF 补充的 `user_id` 字段，但不以该字段作为身份依据。
- `ReadingTraining.tsx` / `ReadingImport.tsx` / `ReadingProgress.tsx`：课程任务、练习、导入和学习情况。
- `CourseStudyPanel.tsx` / `app/page.tsx`：现有课程工作区、专注布局及 `?notebook=…&reading=…` 深链接。
- `data/reading_examples_v1.json`：两篇原创体验示例及预置解释，无运行时外网或模型调用。

订正后的「问小知」使用现有课程对话入口及统一模型网关。确定性判分、保存、导入和复习调度均不调用模型。

## 可重复验收

后端：使用独立 `DATABASE_URL` 运行 `backend/tests/test_reading_training.py`；仓库要求的全部后端回归也须通过。时间推进用受控测试时钟，不能称为已等待真实一天后的真人长期使用。

前端：`frontend/e2e/reading-training.spec.ts` 覆盖真实 BFF 登录、跨浏览器恢复、首次作答、订正、提前复习、导入、原文证据错误、服务失败、并发冲突、多标签页草稿、章节导航及手机布局；`course-study.spec.ts` 回归五门课程。

统一入口：

```text
python scripts/acceptance.py local --scope ui --suite reading-training
python scripts/acceptance.py live --suite reading-training --expected-commit <完整提交号> --identity <部署SSH密钥路径>
```

线上入口复用同版本发布锁，使用独立验收账号及原创测试材料，不调用真实模型。测试目录中的 trace 可能包含测试登录态，位于忽略目录，不提交或公开分享。

本轮运行结果和截图索引交付在工作区独立验收报告。功能验收不证明英语学习效果或考试提分。
