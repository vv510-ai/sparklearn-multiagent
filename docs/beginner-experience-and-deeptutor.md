# 聊天可用性、新手测评与 DeepTutor 借鉴

核验日期：2026-09-18。本文区分实际落地、现有能力和后续候选，不把开源项目的能力当成本项目已有能力。

## 1. 聊天输入框为什么看不见

课程信息栏加入后，中间列里的聊天组件仍使用父容器的全部高度。信息栏与聊天组件相加超出容器，底部输入框被 `overflow-hidden` 裁掉；不是聊天接口被删除。

修复前在生产站创建隔离测试账户，进入六级课程后，Playwright 断言输入框在视口内失败，实际可见比例为 0。仅检查输入框存在或接口成功不足以发现这个问题。

修复：中间列改为纵向 flex，信息栏占实际高度，聊天区使用剩余空间；消息列表可以滚动，输入区保持可见。补充明确输入标签、中文输入法组合状态保护、窄屏标题栏收缩。根容器使用 `overflow: clip`，避免内部自动滚动把整个工作台横向移走。

验收覆盖 1440×800、1280×650、390×844、640×420；检查输入框和发送按钮的完整可见性、中心点可点击性、真实发送与追问、账户内消息保存。

## 2. 测评依据及其边界

- **题目范围**：按当前课程知识点组织。六级的模块安排参考[教育部教育考试院考试结构](https://cet.neea.edu.cn/html1/report/16123/201-1.htm)，题目为项目原创。官方结构不证明我们的题目难度、效度或分数换算准确。
- **判定规则**：每个模块先收集 3 次作答；不足 3 次为待测。0–1 题正确安排基础学习，2 题正确安排巩固，3 题正确安排换题验证。题目难度是人工标注，没有 IRT 校准，也没有经过信度、效度或预测分数验证。
- **证据分开**：不会记为当前困难；跳过不记错；信心、速度和自述不增加正确率。入门测评、看过解析后的练习、独立新题、实际写作和翻译应分别记录。
- **六级默认入口**：先看 2 个模块，最多 6 题。其他模块保持待测，允许继续补全；全面摸底仍为原有 18 题。已经开始的旧测评保留原范围，不偷偷改变已有作答。

学习安排参考 [IES 学习与教学实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：例题与独立练习交替、分散学习有中等证据，提取练习有较强证据。该指南对用前测定位需学内容的证据评级较低；它不能为本项目的“每模块 3 题”阈值或“6 题入口”提供测量学背书。6 题是降低初次使用负担的产品选择，尚需真实用户测试。

### 本轮交互修改

1. 可展开的不计分操作演示，只练“选中 → 提交”，不教授正式题目答案，也不写入学习证据。
2. 每次一道题，中文说明操作要求；整行选择、已选提示、明确提交按钮。
3. 信心记录变为选填折叠项；继续保留不会、跳过、暂停与账户续答。
4. 复盘明确标注已提交，一次查看一道题；显示完整选项、自己的答案、参考答案、原因和听力复听入口。
5. 已有报告从保存的题目快照补全显示信息，不重算历史成绩；补测未完成时不提前透露新题解析。
6. 复盘可带着当前题的上下文进入小知对话。课程目标、材料绑定、账户隔离沿用现有实现。

对初学者更清楚是本轮的设计目标；尚无用户研究证明其完成率或学习效果已经改善。后续应先观察首次成功作答、暂停后继续使用的情况和用户反馈，再决定是否增加题量或改进题目。

## 3. DeepTutor 查到了什么

官方项目：[HKUDS/DeepTutor](https://github.com/HKUDS/DeepTutor)。本次核对提交 `897fce52f24bf22e6e50d8a3e4df532632a26322`（2026-09-14），许可证 Apache-2.0。读取了官方文档以及聊天输入、答题卡、学习路径和掌握状态循环相关源码；未安装或运行其完整服务，不能声称比较过其实际学习效果。

| 观察到的做法 | 对小知的价值 | 当前处理 |
| --- | --- | --- |
| 输入区在学习工作台持续可用，工具与参考资料有独立区域 | 学生随时能提问和回答 | 本轮修复输入区布局和移动端可见性；设计借鉴 |
| 问题使用专门卡片，有选择、提交、跳过、批阅状态 | 不让学生猜测在哪里回答 | 本轮加入操作演示、中文要求和清晰复盘；设计借鉴 |
| Goal → Materials → Outline，用户能核对范围和遗漏资料 | 让计划与目标、教材一致 | 本项目已有目标、资料绑定和范围确认；未新增 DeepTutor 服务 |
| 按知识点类型决定掌握证据，学习与复习状态明确 | 选择题不能代替写作等完整能力 | 六级现有实际写作、翻译、新题及复测继续保留；更细类型模型为候选 |
| 知识库有解析状态、文件预览和独立索引版本 | 让检索覆盖与来源可检查，重建失败不破坏旧版本 | 索引版本切换、更多解析后端为后续候选，本轮未集成 |

## 4. 回归入口

- 后端：`tests/test_beginner_assessment.py`（短测范围、补测不重复、不提前泄露解析、历史快照兼容、多选记录）；全量后端测试必须通过。
- 前端：`e2e/beginner-experience.spec.ts`（可见性、发送、输入法、操作演示、暂停续答、复盘）；`entry-assessment.spec.ts`、`cet6-course.spec.ts` 检查原有学习链路。
- 构建：`npm run build`。
- 生产：按仓库发布流程提交到 main，经 ECS 构建和健康检查后，在公网重新执行浏览器核心流程；本地 mock 测试与生产真实模型验证分别报告。
