# 真题词句与复习连接

目标：真题清晰文字点词、选句拆解、按义项保存原句、进入到期复习、返回原题。沿用现有题源边界、账号隔离、FSRS 与模型网关，不新增模型供应商或数据库表。

现有基础（2026-10-05 源码核对）：PDF.js/fflate 读取原站试卷；VocabularyCard 按账号、课程、词条和义项保存；py-fsrs 6.3.2 已集成。缺口是新版 Cet6Exams 未接词汇收藏、WordRound 未显示原句。

取舍：复用现有调度与修订号/幂等机制，不另建复习服务；收藏待练独立于已学习轨迹，避免虚增词表覆盖。句子请求只发送用户选择的短摘录，不发送参考答案。模型输出校验只能确认格式与引用，不能证明语言分析无误。

验收：后端隔离、重复收藏、首次待练、重新收藏不改变已有安排、回忆后调度、帮助记录；前端构建；浏览器实际点词保存、刷新恢复、到期复习、返回原题及手机布局；生产同版本锁下验证真实模型拆句。写作多轮修改、错题专项复习与口语属后续阶段。

## 使用路径

1. 大学英语六级 → 真题练习 → 阅读 → 仔细阅读（也支持选词填空、段落匹配）→ 选择套卷。
2. 在“清晰文字”中点单词，核对本句义项，点击“加入复习，保留原句”。也可从段落下方“拆解句子”选择句子，查看主干、分句和理解自查。
3. “今日复习”或词卡内“现在复习”直接打开到期复习；没有到期卡时显示说明并返回词汇列表。新收藏首次待练不增加已学词数，实际回忆后才产生调度记录。
4. 先看原句回忆，翻面后显示语境笔记和“回到原题 · 第 N 题”。保存评分后进入下一张；中途刷新可以恢复。

## 边界与恢复

- 扫描卷维持原版阅读，不把未识别文本补造成可点词文字。词形查询优先使用可追溯映射；未收录时提供词典查询和语境拆句入口，不凭后缀猜释义。
- 义项由学习者结合原句选择。原卷摘录来自浏览器，只标注为学习者选择的摘录，不声称服务端已逐字核验题源。
- 句子讲解由 AI 生成，原文片段引用与返回格式会检查；理解自查为自评，不计考试成绩或自动判断掌握。演示环境明确返回不可用，不提供伪造讲解。
- 收藏用修订号与幂等请求保护。响应丢失可重试；其他页面修改词卡后，可重新读取而保留原句和笔记。
- 作答中的帮助标记只能由 false 变为 true，首次提交后冻结；重新作答开启新一轮。冲突保留草稿时合并服务端帮助标记，防止保存循环。
- 不新增数据库表与依赖；原词汇卡 JSON 增加可选的 `queued_at` 和出处字段。回滚应用不会删除已有学习记录。

- 当前题内关闭再打开保留笔记草稿和已完成的拆句结果；关闭弹窗不会取消正在进行的请求。未保存草稿不承诺跨刷新恢复。

## 2026-10-07 原文词形查询

- 新增 `/word-lookup`，用于精确词形解析；普通词表搜索也优先显示匹配到的原形，保留原有级别、专题及收藏过滤。`stopped / stopping → stop`、`studied / studies → study`、`children → child`、`went → go` 等不调用模型即可查询。
