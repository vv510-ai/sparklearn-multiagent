## 3. Docker 安装后执行

在仓库根目录运行：

```powershell
docker compose up -d --build
docker compose ps
Invoke-WebRequest http://127.0.0.1:8000/api/health -UseBasicParsing
Invoke-WebRequest http://127.0.0.1:3000/api/health -UseBasicParsing
docker compose logs --tail=100 backend frontend
```

容器内运行金样（只读挂载测试目录，不把测试文件打进生产镜像）：

```powershell
docker compose run --rm --volume "${PWD}/backend/tests:/srv/tests:ro" backend python tests/smoke_multimodal.py --golden
```

关闭容器但保留数据库：

```powershell
docker compose down
```

不要在仍需保留数据时使用 `docker compose down -v`。

## 6. 故障演练结果

三套演练均在独立进程中覆盖环境配置，不改 `.env`，不写假成功：

| 场景 | 实测结果 | 主链路策略 |
| --- | --- | --- |
| `DEMO_MODE=true` 且无任何密钥 | OCR 返回既有演示题面；TTS/文生图/视频返回 `degraded=true`，耗时 0ms | 文本与本地演示链继续，外部媒体不阻塞 |
| 仅保留文本大模型密钥 | OCR 走本地 RapidOCR；TTS/文生图/视频返回 `credentials not configured` | 图片资料仍可入库；资源视频继续使用脚本 + 本地 Manim |
| 单独关闭 `MM_TTS_ENABLED=false` | TTS 立即返回 `capability disabled`、`degraded=true`，耗时 0ms | 只缺旁白，不影响视频脚本、Manim 与其他资源 |

此外，真实账号演练结果为：TTS 成功；讯飞 OCR 返回 `11200` 后本地 OCR 成功；OpenAI 文生图额度受限后回退星火，星火返回 `11201`；Seedance 模型服务尚未开通。四种结果均被网关归一化，不向资源主链路抛异常。
