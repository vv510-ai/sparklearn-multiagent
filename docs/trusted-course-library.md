# 可信课程库第一阶段

用户已选择“完整课程优先，英语小规模试点”。本次实现课程库基础与 Python 十课试学；英语影视场景尚未发布。

## 学生能做什么

打开 `/library`，登录后直接开始，无须上传资料或先通过测评。十课包含官方教程原文、本站导学、已执行核对的例子、独立新题、隔日替换题与动手任务。阅读、答题、自述是否参考、代码和自查分别保存；代码提交不自动判定掌握。电脑、平板和手机共用账号进度。

新课依次覆盖运行、变量、条件、循环、容器、函数、模块、文本文件、异常、学习记录统计。它是约定范围内的入门课，不代表大学 Python 整学期大纲。保留旧版四门课程和已有笔记本。目录说明其他课的实际覆盖范围，不给未接入完整教材的课程加“完整”标签。

## 来源与边界

官方原文为仓库内固定的 Python 3.14.7 中文教程 18 个小节，保存逐节 URL、版本、正文哈希与 PSF 许可全文。界面区分官方原文、本站原创导学、AI 生成答疑。十课导学和题目由 AI 辅助编写；示例与题目经真实 Python 执行验证，尚未经教学专家审定，也未做真实学生学习效果试验。逐题解释与编码任务仍应安排教师复核。

每课第一道新题立即可答；第二道是不同题，第一题提交一天后解锁。答案不会随未作答题目下发。相同提交可安全重试，旧页面写入返回冲突，独立作答只表示学生自述。

## 内容版本与撤回

`CourseRelease` 保存不可变内容和发布前预计算索引，`CoursePublication` 指向当前版本，`CourseStudy` 保存账号所属进度与固定版本。更新先构建再切换，旧学生继续旧版。新版本不能覆盖旧版本 ID。

撤回以整份受影响课程版本为最小单位，保留用户记录但隐藏正文、源生答案与相关资源。源正文哈希撤回有持久记录，改版本号不能重新发布同源内容。聊天保存显式版本；引用保留原编号；笔记携带来源且只在同一发布版本中复用。接口与静态资产入口检查撤回，媒体轮询和音频重试也复查。已经被用户下载或外部服务直接交付的副本无法由网站收回。

公开课程索引集中保存，不向每个账号复制正文；问答只计算问题向量。索引指纹包含模型、维度、可用的权重和分词文件摘要、分词库及处理版本。模型不同即拒绝旧索引并要求重建；切回旧索引不能只依靠维度相同。正文阅读不依赖向量模型。暂不引入新向量数据库。

## 运维

在使用与服务一致的数据库和嵌入配置的后端环境中执行；先审核内容与许可。运维命令没有公开 HTTP 管理接口。

```sh
python scripts/manage_course_library.py validate app/data/course_library/python-foundations-v1.json
python scripts/manage_course_library.py publish app/data/course_library/python-foundations-v1.json
python scripts/manage_course_library.py activate <existing-release-id>
python scripts/manage_course_library.py withdraw <release-id> --reason "撤回依据"
python scripts/manage_course_library.py withdraw-source <source-sha256> --reason "撤回依据"
```

`activate` 可选择未撤回的旧版，按当前模型重建其索引后切换。学生绑定的版本不会自动迁移。撤回的版本禁止恢复；需更换有合法使用依据的材料并发布新 ID。新课程材料构建需显式传 `--release-id` 和新 `--output`，拒绝覆盖已有文件；来源版本混杂时停止。

## 验收与后续

后端检查内容实例执行、账号隔离、重试与冲突、发布失败、旧版保留、来源撤回、无引用流式历史、媒体旁路、笔记来源、查询不重算正文、模型变化拒用。浏览器检查注册后零上传开课、保存草稿、刷新恢复和三种屏宽。生产通过 `scripts/acceptance.py live --suite trusted-course --expected-commit <full-sha> --allow-live-models`，持有部署锁后验证同版 UI 和一次带官方引用的真实问答。
