# SparkLearn 星火学伴 · 测试说明书

## 1 测试概述

测试目标是验证五大功能(画像、资源生成、路径规划、智能答疑、学习评估)的正确性与闭环性,验证多智能体编排的并行与容错行为,验证防幻觉机制有效,并确认系统在无密钥离线环境与有密钥联网环境下均可稳定运行。测试方法包括单元测试、端到端冒烟测试、接口测试与人工演示走查。

## 7 性能与并发观测

演示模式下(模拟打字机间隔 12ms),生成链路端到端约 4–6 秒完成 30 个事件;答疑首 token 小于 200ms。联网环境的预算指标为:答疑首 token ≤2s(星火流式),四资源并行生成总时长 ≈ 单个最慢资源(文档,约 20–40s)而非四者之和,视频走异步任务不计入阻塞时长。SSE 连接在 Nginx/Node 代理下需关闭缓冲(已在响应头设置 `X-Accel-Buffering: no`),实测无粘包丢帧。

## 8 防幻觉专项测试

构造三类输入验证双层校验:其一,正常知识点生成,grounding 判定 grounded=true,卡片无复核标记;其二,在演示语料外追问细节,生成文末出现"溯源提示"块且资源标记"溯源复核";其三,在输入中夹带敏感词,safety 事件触发、safety_flags 落库。引用脚注 [^n] 与页脚 CITATIONS 编号一一对应,抽查 10 处引用均能在 `seed_corpus` 对应章节找到原文依据。

## 9 兼容性

前端在 Chrome 120+/Edge 120+ 验证通过;Firefox 下 SSE 与 SVG 渲染正常;1280px 以上桌面为主要适配目标,窄屏自动隐藏右侧遥测栏。后端在 Python 3.10–3.12 验证;SQLite 与 PostgreSQL 双库通过同一套 ORM 跑通。

## 10 缺陷记录与回归

| 编号 | 现象 | 根因 | 修复 | 回归 |
| --- | --- | --- | --- | --- |
| BUG-01 | 编排在 planner 后中断 | f-string 内字典下标漏引号(`plan[resources]`) | 加引号并全仓正则扫描同类写法 | E2E-01 通过 |
| BUG-02 | 题组只剩 1 道兜底题 | parse_json 恒先匹配 `{`,顶层 JSON 数组被截成首个对象 | 按 `{`/`[` 先出现者决定截取顺序 | E2E-01/03 通过 |
| BUG-03 | media 节点不执行 | kinds 中的 video 未映射到 media 节点 | 建立 kind→node 映射表(code/reading→doc,video/audio→media) | E2E-01 通过 |
| BUG-04 | 答题落库报字段错误 | QuizAttempt 实体为整卷 score+detail,接口按逐题字段写入 | 接口改为整卷一条记录,报告端同步改聚合口径 | E2E-03 通过 |
| BUG-05 | 资源详情 payload 双重编码 | JSON 列已自动序列化,代码又手工 dumps | 直接存取 dict,并加历史数据兼容读取 | F2-5 通过 |

全部缺陷修复后,单元测试 3/3、端到端 3/3 全部通过,作为基线纳入回归集。

## 11 测试结论

系统五大功能在离线演示模式与设计的联网模式下均满足需求;多智能体并行编排、SSE 实时遥测、防幻溯源与评估闭环等关键特性经端到端验证有效;已知缺陷全部闭环。系统达到参赛演示与评审标准。
