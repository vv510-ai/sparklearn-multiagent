# 一图看懂：小云雀生图与成图核对

## 问题与处理

此前为了防止图片中的错字与错误符号，一图看懂被改为本地 SVG。现在恢复用户要求的流程：整理并核对知识底稿 → 小云雀生成信息图 → 独立检查实际图片的文字、公式和关系 → 明确错误最多修正重画一次，检查不可用或仍有问题则提示。保持原有资料边界、来源引用和完整文字版。

- 生图固定调用已有小云雀适配器，不在失败时切换其他生图供应商。
- 读图先只看实际图片，不提供预期底稿；之后统一文本模型网关对比底稿与读图记录。学习画像不进入这两个检查提示。
- 仅对本地生成的 PNG/JPEG/WebP 读取图片字节；本地文字 OCR 不能替代连线关系核对。
- 三个维度完整通过且没有疑点才标记自动核对完成。任何超时、降级、空白/缺失字段和不清楚的关系均不会通过。
- 生成失败保留文字和出处；检查不可用不继续付费重画。明确发现错误最多重画一次，并重新检查新图片。
- 每页保存供应商、提示版本、生成次数、检查结果；完成读图对比时保存图片与底稿 SHA-256，便于追查。
- 已有 SVG 与旧图片资源仍可阅读。过密内容沿原有小节最多拆两张，单张超出范围则明确提示，不静默截断。

## 验证范围

- 后端回归覆盖真实路由参数、严禁供应商静默降级、盲读图、无效核对不得通过、一次修正与复检、失败保留原图、拆页、账户缓存隔离。
- 浏览器分别验证核对通过、仍有错误、无法检查、图片未生成四种界面状态；其中状态样例是明确的响应夹具，不证明模型识别能力。另验证课程资料和自然追问链路。
- 真实小云雀样例：栈与队列，生成了一张 JPEG。人工查看发现队列重复元素，不能认定图片内容合格。已增强提示中的元素数量、状态、输入输出顺序规则。
- 本地及生产现有星火图片理解服务均返回 401。这个实测验证了检查不可用时明确提示的分支，不能证明真实的自动识错与重画已经验收通过。完整自动复核仍依赖可用的图片理解服务。
