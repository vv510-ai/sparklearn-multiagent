# 六级词表覆盖与可选背词顺序

日期：2026-10-04。

## 用户需求与行为

完整保留备考词表，默认优先学重点词；学习者按习惯选择顺序，并能看到已学词与备考范围的进度。重复的“考试与目标”入口并入“备考建议”。题源证明单独交付项目拥有者。

- 背单词 → 背词设置：重点词优先、词族一起背、字母顺序、打乱顺序；每日新词额度继续独立设置。重点指官方大纲标星的六级新增词及其派生词，内部再按 ECDICT 通用词频安排，不声称是历年真题考频。
- 词族一起背：依据大纲同一原行的原词与派生关系安排，例如 able / ability、connect / connection / connexion。每天额度之外的词顺延；不强制超过每日学习量。
- 词表可以按词族查看和筛选整个词族。多行同形词选择稳定主行，不跨行传递合并：tyre 不会与 tired / tiring 因 tire 的两种含义而误连。所有原始定位关系仍保留；这不是完整的词源学关系库。
- 改变顺序时，未开始词重排，已经打开的词卡轮次继续恢复；降低额度、跨天、重复回忆和拼写模式不清除历史。新词每轮最多 5 个，复习每轮最多 20 张。
- 两项进度为“六级重点词”和“完整备考词表”。同一单词练多个义项或拼写只计一次；至少完成一次回忆即记为已学，不等于已经掌握。统计限定账号和课程。
- 只保留“备考建议”入口，目标概览、修改偏好和折叠考试说明位于同处；旧 `cet6=examinfo` 链接转入该页。首页已有目标分数或日期时不再显示“目标还未填写”。

## 词表的数量与校正

来源为[教育考试院当前大纲入口](https://cet.neea.edu.cn/html1/folder/16113/1588-1.htm)所列 2016 版词表。原始数据和此前逐行审计未被修改。本轮有效词条仍覆盖已提取的全部 5,377 个可见原行，含基础词和派生词；不把词表去重展开后的学习词条数写成官方要求的独立词头数。

原始 8,014 个展开词条中，4 个缺乏独立词义依据的展开异体并入常用拼写：Celcius → Celsius、honourary → honorary、instalation → installation、sobre → sober。它们均原无义项，原 API 无法为其创建有效练习；旧 ID 可解析到目标词，原定位也在目标词中保留。有效学习词条为 **8,010**，其中大纲六级标记及其派生词 **1,724**，其余 **6,286**。

大纲原行确实存在上述缩写/可选字母形式，故不把它们一概称为“大纲错误”。另外，程序对 `connection/-xion` 的展开确有错误，显示拼写 `connecxion` 已修正为 `connexion`，保留原词条 ID；构建脚本同步修正该展开规则。

补齐 connexion、cliché、coup d'état、microwavable、résumé 的释义，并为 a / an 增加不定冠词的首选释义。补充内容为依据 Merriam-Webster 的中文概括，来源逐项记录在修正 JSON 中。所有有效词条都有释义；这只证明不存在空释义，不表示 8,010 个词的全部旧释义已经逐条人工审校。显示层清理字面 `\r`、`\n`、`\t`，旧义项 ID 均保留。

## 实现与验证

复用已有 Preferences revision、VocabularyDay 日计划、VocabularyCard 义项记录及 FSRS 调度，不新增数据库表或更换复习算法。顺序偏好默认 `priority`，旧偏好数据读取时自动获得默认值。大纲原始 JSON 保持原样，修正层拥有独立版本。

针对词表范围、释义兼容、词族误联、默认重点优先、同族相邻、随机刷新稳定、已打开轮次、跨天、覆盖去重与权限隔离增加行为测试；新增浏览器流程覆盖四类核心行为：词族筛选、顺序保存、手机覆盖展示、合并入口与旧地址。

独立复核发现 tire 的同形异义会通过传递分组错误连接 tyre 与 tired；已改成按稳定主行分组。复核确认 8,010 词各归属一次，5,316 组均共享明确原行，保留词条的旧义项 ID 丢失数为 0。

本地最终验证：完整后端 **763 passed**（`.tmp/acceptance/20261004T152203Z-local/report.json`）；前端 Turbopack 与 webpack 构建通过；六级、章节和阅读浏览器回归 **28 passed，0 skipped，0 retries**（`.tmp/cet6-vocab-ui-final/playwright.json`）。另有 3 项针对性复测通过（`.tmp/cet6-vocab-rerun/playwright.json`）。完整回归前的失败记录保留：旧测试数据库缺字段、外链一次读取失败、两个测试对新排序/控件定位的旧假设，以及原本地进程退出后的连接拒绝；最终采用新临时数据库和新服务进程验证。

本地离线精讲用例遵守实际状态：重点排序不保证首词属于少量预整理讲解，未接模型时显示服务不可用，不伪造讲解结果。生产验收使用 `scripts/acceptance.py live --suite cet6-exams --expected-commit <release> --allow-live-models`，在同版本锁内检查真实公开网站，具体版本与结果保存在该次验收报告中。
