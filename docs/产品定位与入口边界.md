# 知行循证：产品定位与入口边界

更新日期：2026-09-16。此文用于团队决策，依据本轮用户确认的产品方向。

## 产品与用户

定位：基于资料与学习反馈的 AI 个性化学习平台。帮助有明确学习任务的个人学习者理解资料、解决问题、练习、获得反馈和安排复习。

当前优先做好课程学习、复习和自主学习。知识图谱、内置题库与起点测评主要覆盖《数据结构与算法》；用户资料学习与内置课程测评的范围要分别说明。其他课程、备考和职业技能是可以逐项适配的方向，不能声称已具备全学科测评能力。

教师和教学研究人员是扩展服务对象。现有 `/teacher` 提供研究方案、匿名观测导入、前后测比较和共性错因查看，页面称为“教学研究”。它尚不具备完整的班级、课程和作业管理能力。

## 页面安排

| 页面 | 用户任务 | 本轮处理 |
| --- | --- | --- |
| 登录、学习首页、学习工作台 | 开始学习、管理资料、处理当前问题 | 移除项目证明材料与教师试点链接，保留测评与计划、学习记录、练习和资料依据 |
| `/review` | 无需登录体验一次练习和反馈 | 保留实际作答、提示和复测；说明固定示例与记录范围，提供回到学习的入口 |
| `/evidence` | 已退出产品的旧页面 | 服务端重定向到 `/`，旧书签仍可回到学习入口 |
| `/teacher` | 教学研究与匿名观测管理 | 保留独立地址及账户隔离，移除项目材料链接，不放在学生主导航 |
| `/api/competition` | 原参赛条款接口 | 移除后端路由与公开访问例外，不再由应用提供评分和申报材料 |

个人学习记录继续解释首次作答、提示使用、复测与复习如何影响掌握度估计。不能把去掉参赛展示理解为去掉作答依据、引用或可靠性说明。

浏览器复核还发现“学习首页”按钮只重置了工作台状态，没有渲染已经存在的首页组件。本轮接回该组件，使按钮能够回到资料与目标入口；完成引导的用户登录后仍直接进入工作台。

## 参赛材料

赛道、评分条款、申报资格和补证清单保留在 `docs/guochuang-2026/`，由负责人查阅和准备。历史结构化登记代码仅供团队导出参考，已无产品 API。已有历史验证记录只代表其记录日期，不作为当前功能或真实教学效果的声明。

## 后续功能取舍

新增功能必须说明实际使用者、要完成的任务和可观察的改进。优先完善学习任务；教师功能根据真实教学需求逐项建设。比赛要求影响申报材料的组织，不决定普通学习者的主导航。

验证范围：后端路由和账户隔离、前端构建、登录与学习请求、测评计划、练习体验、旧地址跳转，以及桌面和手机页面。工程验证不代替真实教学效果研究。

本地验证结果：285 项后端测试通过；Next.js 生产构建通过；6 项浏览器测试通过，并回看桌面与手机截图。浏览器的本地学习请求使用离线引擎；生产验证另行记录。
