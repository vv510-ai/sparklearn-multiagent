# 反馈 05：数学公式和符号排版

对应《项目网站用户体验问题反馈.docx》的“符号格式不标准”及 image4、image5。一次处理这一项；验收对象是题干、选项、解释和学习正文的显示，不是证明 AI 数学推理始终正确。

## 证据和原因

- 生产基线 `0ec8266`：真实注册、选择高数、进入起点测评，第 3 题是普通文本 `∫₀¹ 2x dx 的值是？`，没有数学排版节点。桌面和手机截图保存在 `.tmp/feedback-05/before/`。
- `Markdown.tsx` 原来只接入 GFM，`$\lim...$` 和 `$\frac...$` 不会排版。测评、练习、复盘等又直接输出字符串，单独修改聊天组件不能覆盖它们。
- 内置积分题使用 Unicode 上下标；旧课程和作答快照已经保存这些字符串。只更新题库不会修复已有记录。

## 实现和取舍

1. 使用 `remark-math@6.0.0`、`rehype-katex@7.0.1`、`katex@0.16.47`，锁定依赖及字体资源。KaTeX 使用插件所支持的 0.16 系列，不同时引入另一套数学引擎。
2. 共享公式管线用于聊天、笔记、测评、复盘、练习、错题本与复习队列。题目中的普通文本保持原样，只有明确数学区域参与排版，避免把 Python 的乘号当成 Markdown 强调符。
3. 新建高数课程中的复杂分数、积分题和相关选项、解析改为 `$...$`。共享讲解规则规定行内 `$...$` 和独立 `$$` 格式。现有保存内容中可明确识别的简单 Unicode 定积分做显示兼容；不迁移数据库、不改答案或成绩。
4. 长独立公式在自身区域滚动；保留 HTML + MathML。字体随本站构建发布，无须依赖外部 CDN。
5. 保留代码内容、转义金额和成对价格；未完成或不合法的 LaTeX 保留可读原文，不使整段回答崩溃。`trust: false`，限制扩展次数和自定义尺寸。

采用的是 [react-markdown 官方公式集成方式](https://github.com/remarkjs/react-markdown#use-remark-and-rehype-plugins-math)。[KaTeX 配置文档](https://katex.org/docs/options.html)说明了 MathML、信任边界、尺寸和宏展开限制。本轮核对了已安装插件源码及 MIT 许可；没有复制第三方源码。字体和依赖许可随 npm 包保留。

## 手动复验与边界

1. 刷新网站，进入高数起点测评：积分上下限应紧贴积分号；选项仍能点击和提交。
2. 查看复盘：题目和解析均可阅读，原作答仍在。
3. 提问“解释 x 趋近 2 时 (x²−4)/(x−2) 的极限”：回答中的分数和极限应排版，公式区域里不应直接出现 `$`、`\frac` 源码。
4. 手机查看长独立公式：只需滑动公式区域，整页不横向溢出。

本轮支持明确的美元分隔 LaTeX，以及已有题库中可无歧义识别的简单 Unicode 定积分；不会猜测所有普通文本表达式，错误/未闭合 LaTeX 仍可能显示原文。SVG 知识图及其他媒体导出不属于本轮排版范围。
