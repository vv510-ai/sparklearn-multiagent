# 英语场景：接入方式与生成可靠性

核验日期：2026-09-26；实现基线：700c6f5558a337a351598f912905acabea288457。

## 决定

保留现有 Next.js / FastAPI / 统一模型网关和 english-vocabulary-notes 的教学原则。
把已发布的三课原创场景放到当前英语入口；自定义生成继续服务用户提供的词表和字幕。
优先保证对话、词汇、笔记可保存和恢复，练习失败可以单独补生成。不替换整套英语应用，不新增数据库、模型供应商或词典抓取服务。

这是针对当前功能的有限范围调研；核验了产品文档、公开仓库、当前提交、许可证与相关故障记录，没有安装或实测这些外部应用，也没有声称穷尽项目或证明其教学效果。

## Skill 的应用边界

网站读取 backend/app/prompts/english/scene.md，而非用户电脑的全局 SKILL.md。
吸收情境义项、搭配辨析、主动回忆，以及用户字幕/原创例句/AI 助记的来源区分。
自动词典核验、多材料全文复读、词源考据、Anki 导出和 FSRS 调度尚未在此入口实现。
维护全局 Skill 不会自动同步生产 Prompt；本次只改产品适配层。

## 故障证据和实现

截图当次缺少原始模型响应，不能确定具体供应商原因。
修复前两项固定用例均复现旧 502：三选项题目使有效笔记整份被拒；限流第一次失败后不重试。
当前处理：

- 全部文本调用继续经 llm_complete；场景关闭深度思考以保留短结构化任务的正文预算，沿用 JSON 模式和字段验证。
- 场景正文最多两次尝试；格式、截断、空正文、连接、限流、上游临时失败可以一次修复或重试。
- 认证、额度、内容过滤、超时不盲目重试；整项生成最多等待 135 秒，低于前端 180 秒等待。
- 来源身份由程序设置；真实字幕仍检查原句并推导时间戳；无字幕清空模型编造的时间。
- 先检查并保存对话、翻译、词汇和笔记；练习独立验证。缺失、选项重复或答案非法时返回 partial，不展示坏题。
- 练习补生成使用已保存的内容，由 resource_id + 账户 + notebook 验证范围。已有题不重复调用，写回前重新锁定检查资源。
- 新增最近场景读取，按账户和课程隔离。生成失败不清空上一份结果，回到页面可恢复最近保存的内容。
- 日志仅记查询编号、能力、尝试次数与错误类别，不记录用户字幕、原始模型输出或凭据。
- 显示具体失败提示和查询编号；可选上传、详细笔记收起；提供现成场景课程和三个自定义场景示例。

现有后台 generation_jobs 只编排聊天及资源图，本入口为短结构化请求；本轮未扩展后台工作进程的业务分支。
本次保证已保存内容可恢复，未承诺进行中的自定义生成在服务器重启后继续执行。
超时发生时底层传输可能仍在结束，本轮不再重叠启动一个新请求；认证失败不会无限重试。
来源检查保留现有字幕匹配边界，本轮没有新增逐句结束时间、媒体哈希绑定或语音评分。
