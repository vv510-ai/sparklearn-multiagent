# 知行循证 / LearnLoop：2026 国创改造交付

**定位：面向高校专业课程的可验证个性化学习平台。**

**选赛道：高教主赛道 → 本科生组 → 创意组 → 人工智能+。**

核验日期：2026-09-15。源版本：258b852。用户确认：普通本科在读，尚未注册公司。

## 1. 为什么这样选

项目已有高校专业课原型，以人工智能支持学习诊断、补救和复测，符合“人工智能+”应用方向。负责人学籍及未注册状态支持本科生创意组。红旅赛道需要相应活动与实践基础，产业赛道需要对接具体命题；当前材料没有这些依据，因此主选高教主赛道。

直接核验依据：[教育部正式通知](https://hudong.moe.gov.cn/srcsite/A08/s5672/202607/t20260731_1445670.html)、[附件1：高教主赛道方案，第2—3页](https://hudong.moe.gov.cn/srcsite/A08/s5672/202607/W020260731408855761133.pdf)。评分采用用户文件《中国国际大学生创新大赛（2026）评审规则》第1—2页。17页“规则变化”PDF是辅助解读，不增加官方未规定的门槛。

报名前仍需核验：团队3—15人，全部为全日制在校本专科生；负责人和成员年龄符合限制；学籍按正式通知时点；教师不作为参赛成员；项目不是不符合例外条件的学校科技成果转化项目；并检查往届总决赛获奖限制及知识产权。**全国报名截止2026年9月25日12时，届时名称、类别、成员等信息锁定；校内截止可能更早。**

## 2. 改造后的核心叙事

让每一次真实作答，都成为下一步学习的依据。

服务对象：高校专业课程的学生及课程教师。现阶段以数据结构与算法验证。核心问题：学生看完讲解后是否能独立完成、错误来自哪里、接下来应该学什么；教师如何识别共性薄弱点并验证教学改变。

产品链路：课程资料与引用 → 初次作答 → 提示/揭晓标记 → 错因与先修缺口诊断 → 补救资源 → 无提示换题复测 → 知识追踪估计与路径重排 → 间隔复习。

品牌已从“星火学伴 / SparkLearn”更为“知行循证 / LearnLoop”，首页、认证、引导、工作台、PPT和元数据采用新名称。底层数据库标识、Cookie和部署目录继续兼容已有用户数据。名称未注册商标，不使用注册商标标识。

## 3. 本轮实现

| 功能 | 原有状态 | 本轮结果 |
| --- | --- | --- |
| 统一文本模型 | 支持星火和DeepSeek，环境选择存在差异 | 加入Astra Responses API，统一入口供所有智能体调用；流式失败不拼接其他模型或演示答案 |
| 一图看懂/封面 | 一图看懂强制小云雀，其他常用星火 | 按配置调用Sunburst；真实PNG校验，缓存按租户、模型、端点、尺寸及质量隔离；展示模型来源 |
| 图片理解、扫描资料 | 星火图片理解与本地OCR | 加入Astra视觉识别，保留不确定文本标记和图片校验 |
| 语音输入 | 讯飞语音识别 | 加入GPT Transcribe；浏览器PCM16先封装成WAV再提交 |
| 互动讲解/视频旁白 | 星火普通/超拟人语音 | OpenAI TTS；可配置Eleven v3与已授权音色；模型、音色、租户缓存隔离，界面说明AI合成 |
| 复习PPT | 讯飞PPT任务 | 统一文本主脑生成受资料约束的提纲，经结构校验后输出可编辑PPTX |
| 视频 | 小云雀Seedance mini lite | 新增官方Ark Seedance 2.5异步任务；生成不重试，已有小云雀任务仍可查询；保存MP4后提供持久地址 |
| 教师工作台 | 主要为个人学习视角 | `/teacher`：教师自有试点、研究方案、匿名导入、分组阶段统计、知识点薄弱环节、导出原始记录 |
| 证据展示 | 分散在代码和历史文档 | `/evidence`：四维17条评分依据与待补证项目、必要条件、工程验证范围 |
| 三分钟体验 | 存在运维演示操作台 | `/review`：无需登录、两道实际交互作答、提示使用区分与下一步理由；不写个人画像，不作为教学效果 |

教师统计的边界：演示与现场试点分开；导入必须声明知情同意及原始来源；同一人不可跨组；相同记录重复导入不重复计数，冲突拒绝整批；配对限定同一受试者、同一知识点；缺测保持空值。统计是描述性的，不自动得出因果结论。

## 4. 评分覆盖结论

**不能把“功能改完”写成“所有评分条款已经完全满足”。** 评审还要求真实调研、学生成长、成员贡献、应用与产业证据，这些不能用代码、合成样例或接口测试代替。全量逐条对照见 [criteria.md](criteria.md)。当前17项均已登记对应实现或补证方式；其中10项有部分依据，7项待补证，没有标记为完整满足。

原项目优势：可运行闭环、引用溯源、知识图谱/BKT、独立复测和账号隔离。主要短板：真实需求研究、真实课堂效果、可验证学生原创贡献及产业/学校支撑。

本轮填补的是模型适配、教师观测工具、公开证据入口、品牌定位和材料采集方法。最终达标的验收证据由实际调研与课堂研究产生，负责人逐项复核后才能更新“已满足”。

## 5. 模型选择与可用性

推荐配置见 [quality-profile.env](quality-profile.env)，技术对比与复用边界见 [model-research.md](model-research.md)。

图像正式API标识为 `gpt-image-2.5-sunburst`。使用任务适配的旗舰候选，不把GitHub星标或厂商宣传当作本项目“全球最强”的测量结果。

**本地真实OpenAI调用遇到额度阻塞：HTTP429，`credit_balance_exhausted` / `insufficient_quota`。** 模型目录可读，但文字和TTS生成未成功。图像、视觉、转写与原生PPT依赖的真实Astra调用因此没有继续批量尝试。ElevenLabs未配置密钥及音色，不视为已启用。Ark真实创建返回404 ModelNotOpen，需先开通Seedance2.5权限；生产直连OpenAI还需解决连通性。

API余额恢复后，在现有`.env`中合并质量配置（保留原密钥、数据库和认证字段），再执行真实验收。禁止把接口桩测试写成真实模型通过。具体当次结果见 [validation.md](validation.md)。
