# 教学试点与技术对照方案

状态：待研究负责人、任课教师确定并实际执行。时长、样本和分组属于研究设计，不是比赛硬门槛。

## 研究问题与预注册

主问题：在等值的新题上，完整平台能否提高独立完成表现，并在延迟测中保持？次问题：引用溯源、知识结构与作答证据分别带来什么作用？

发放前固定协议版本、纳排标准、样本规模依据、分组方式、课程知识点、材料、模型快照、干预期、等值题组和主要分析。一个可讨论的周期为4—8周，后测后1—2周延迟测；若实际不足，只报告已观测阶段。

## 分层验证

### A. 技术任务对照（不能替代教学研究）

统一模型版本、相同任务与输入资料、相同时间和token预算。比较：

1. 通用LLM：仅允许与学生实际持有资料相同的信息。
2. RAG：加检索和引用，关闭学习状态决策。
3. RAG+课程图谱：加先修结构，关闭作答证据与BKT自适应。
4. 完整平台：提示/揭晓分离、错因、补救、独立复测、路径调整。

消融必须真正关闭对应模块并保存配置；不能只更换页面标题。当前发布版未提供上述四组的独立实验开关，因此不能宣称消融已完成。实验分支核验后记录提交和配置，再执行。

任务集覆盖课程术语、算法边界、资料冲突、未覆盖问题、错因诊断、提示后答对和延迟复习。题目由教师复核，训练/开发题与最终测试题分离。对照题组公开规则，避免提前泄露学生正式测试答案。

指标：事实错误率、引用是否真正支持对应句子、拒答是否合理、错误诊断的教师一致性、完成率、首字与总耗时、实际token/图片/音视频成本、失败率。只比较API模型也应使用相同任务条件；模型升级后的结果不能冒充系统模块收益。

### B. 真实课堂研究

优先随机分组；若按班分组，记录班级、教师及基线差异并承认混杂。平台组和对照组使用相同课程内容、测量工具和学习时长约束。平台学习期间的练习不能直接充当独立后测。

主要指标：后测新题独立正确率。次要指标：延迟测独立正确率、单位学习时间、提示依赖、错误类型变化。题目需覆盖相同知识点和等值难度；不能用相同原题记忆解释成迁移。

独立：题目提交前未使用提示、查看答案、教师/同伴帮助。系统已有支持作答标记可供导出；教师导入的“independent”计数需原始凭证核验。BKT是模型估计，不是真实效果指标。

## 数据字典（对应教师工作台导入）

| 字段 | 含义 |
| --- | --- |
| participant | 同一试点内稳定匿名编号，仅英文数字、下划线或连字符，2—48位 |
| arm | intervention（平台组）或control（对照组），同一人不能跨组 |
| phase | pre / post / delayed |
| knowledge_point | 知识点，配对分析要求前后相同 |
| correct / total | 正确题数 / 总题数，不能用百分数替代题数 |
| independent | 没有使用帮助的题数，不是独立答对题数 |
| minutes | 此阶段用时，正数 |
| observed_on | 实际采集日期，不能填未来日期 |
| consent | 获同意为true；未获同意不导入 |
| provenance | 脱敏原始凭证编号或位置；此声明仍需负责人复核 |
| data_kind | demo或field，须匹配试点性质 |
| errors | 知识或策略错因标签，最多10项 |

JSON格式样例可在教师工作台下载，文件标题明确标记合成演示，不得改名当成真实样本。

## 分析规则

- 同一学生每阶段先按题数合并知识点成绩，再对学生等权汇总；页面显示每阶段实际n。
- 前后变化仅对同人同知识点配对，先求知识点正确率变化，再学生内平均，最后组内平均。
- 两组增量之差是描述量，不自动等同干预因果效应。配对样本与所有阶段样本可能不同，不能直接把表格总体均值相减冒充配对结果。
- 缺测不补零；记录退出原因和各阶段流失。报告保留原始导出，分析副本做敏感性检查。
- 完成真实研究后，根据随机化单位和数据结构，选择ANCOVA/混合模型或合适的稳健分析，报告置信区间和效应量。不得把学生多次题目作答错误当作独立学生扩大样本量。
- 教师盲评先移除平台与模型身份；两位教师独立评分并处理分歧。量表、评分锚点和一致性应留存。
