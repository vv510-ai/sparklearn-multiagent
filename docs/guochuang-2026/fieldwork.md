# 需求调研与产业访谈：待实际执行

目标：证明高校专业课程中存在什么具体困难、现有工具为何不足、哪次观察改变了项目。此文档是研究工具，未记录任何已完成访谈或样本数。

## 学生问卷

开头告知：自愿参与；拒绝不影响成绩；不收姓名、学号和联系方式；用途为课程学习工具研究；可跳过问题；数据保留和撤回方式由负责人在发放前填写。访谈录音另行取得同意。

1. 当前学习课程及年级（可不填）；是否已经学过本课程？
2. 最近一周，哪一具体知识点最难？请描述一次卡住的过程。
3. 学习困难发生在理解概念、读题、先修知识、独立应用还是复习保持？可多选并举例。
4. 最近一次用AI后，是否在关闭答案/提示后完成过新题？频次：从未/偶尔/经常。
5. 遇到无法核验的AI解释时，你如何核对？愿意花多久？
6. 现有工具：教材/教师/同伴/通用AI/课程平台/其他；分别在哪一步有帮助？
7. 提示后答对与独立答对是否应区分？原因是什么？
8. 试用原型完成一项预先统一的任务后：独立完成情况、失败点、耗时、自述困难。不要只问“喜欢吗”。
9. 如果只保留一个功能，你会保留哪个？为什么？
10. 是否愿意继续试用？有什么顾虑？不以奖品诱导积极评价。

## 教师访谈（每次记录30—45分钟为设计建议）

- 最近一门课程中最难发现、最耗时处理的学习困难是什么？展示可脱敏的作业或课堂实例。
- 如何区分学生独立完成与借助答案？怎样设计等难复测？
- 目前判断知识点掌握程度的依据、频次和误差是什么？
- 何种错误诊断会导致不恰当的教学建议？必须由教师复核的部分是什么？
- 教師工作台中的分组、缺测、错误类型及导出是否符合现有流程？当场执行一个任务，记录阻碍。
- 能否开展前测—干预—后测—延迟测？课程日程、班级分组、同意和数据权限有哪些限制？
- 接受采购/部署前会要求哪些证据？由谁决策、经费从哪里来、评估周期多长？

## 学校/企业/采购访谈

对象可以是课程负责人、教务部门、教育技术中心、真实潜在合作方。记录现用产品与替代方案、采购主体、预算形成方式、合同与服务要求、学生数据权限、接入及运维成本。没有预算或采购意愿时直接记“未知/暂无”，不能转换成潜在收入。
